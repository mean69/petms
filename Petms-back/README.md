# PetFave backend

Laravel 13, MySQL 8+, and Laravel Sanctum cookie-based SPA authentication.

See [the workspace README](../README.md) for installation, administrator creation, Google configuration, API routes, testing, and production setup. See [DATABASE.md](../DATABASE.md) for the ERD and normalization explanation.

Quick verification: `php artisan test --compact`. Tests use an isolated SQLite database by default.

Keep `.env` private. Use `.env.example` and `.env.production.example` for configuration guidance.
